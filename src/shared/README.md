# Shared utilities and models

## Feature Flags

Flags are located in the `feature-flags.json` file.

List:
 - `stage_confetti` (default: true): enable/disable confetti animation on successful attempt
 - `streak_reward` (default: true): enable/disable a reward for a player of an additional life for a specified streak of correct answers
 - `simple_login` (default: true): enable profile selector screen when is enabled, and show login with username/password screen when disabled

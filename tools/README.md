# Project Tools

## Feature Flags

HTML application to manage Game's feature visibility. Open `tools\feature-flags\index.html` in a browser.

## Release Report

HTML application that displays the latest release pipeline result (`reports/current-prod-build/release-report.json`). Run `npm run release:report` and open `http://localhost:4784`.

## Templates

Containes for reusable templates for agents and scripts.

## Sync current stack

Updates the Current Stack section in `CLAUDE.md` in case of tech stack change (`npm run docs:sync-current-stack`).
